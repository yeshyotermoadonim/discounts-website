# יש יותר מועדונים

Next.js site that shows which brands are available in חבר שלי, בהצדעה, and ביימי אול.

The listings live in [discounts-data](https://github.com/yeshyotermoadonim/discounts-data). This app fetches them from GitHub and falls back to `src/data/seed/`.

How to refresh the data or publish to Vercel: [UPDATE.md](./UPDATE.md).

```bash
npm run dev
```
